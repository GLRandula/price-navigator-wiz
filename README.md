# Property Price Predictor

I have already built an prediction model for property price prediction. I want to build an attractive web based interface to present this to users. Preffered single page web application for this. Navigation should be included,
- Home
- Features
- Observations
- Predict Price (Get the user inputs from as multistep wizard for different sections.)

Input form should be have following sections as 3 steps.
- Section 01: Reginal Parameters (District, City, Type, Property Type)
- Section 02: Dimension Metrics (House Size, Total Land Size)
- Section 03: Geospatial Anchors (Latitude, Longitude values. User able to pick the location from map and automatically get the values.)

Output also should be given in a pop-up modal as given. Add two seperate tabs in the output pop-up to show prediction output and graphs separately.
